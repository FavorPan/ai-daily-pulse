### [dograh-hq/dograh](https://github.com/dograh-hq/dograh)
- **来源**：GitHub Trending
- **评分**：6/10
- **标签**：`#开源项目` `#语音Agent` `#自托管` `#Vapi替代` `#工作流构建器`
- **摘要**：Dograh AI 是一个 100% 开源、采用 BSD 2-Clause 许可的语音代理平台，可通过一条 Docker 命令完成自托管，对标 Vapi 和 Retell 等专有 SaaS 产品。支持拖拽式工作流构建器，宣称能在 2 分钟内从零构建可用的语音机器人，并允许接入任意 LLM/STT/TTS 提供商，完全避免供应商锁定。

### [Show HN: AnyFrame – Sandboxes for AI Agents](https://anyfrm.com)
- **来源**：Hacker News Show HN
- **评分**：5/10
- **标签**：`#AI Agent` `#沙箱环境` `#开发工具` `#MCP`
- **摘要**：AnyFrame 是一个面向 AI Agents 的沙箱工具，支持 Claude Code 和 Codex 连接任意代码仓库，在秒级时间内启动沙箱环境。通过预缓存镜像机制减少初始化延迟，允许从 Web 或 Python SDK 在同一渠道进行对话，并支持 Linear、Sentry 等 MCP 连接器的热插拔切换。产品提供 Python SDK 和 GitHub 代码仓库供开发者集成使用。

為什麼做這個專案

每天有大量 AI 資訊發布在各種平台上，手動刷太累、也容易漏。AI Daily Pulse 幫你自動從 40+ 個 RSS 資訊源抓取、預篩選、AI 評分與去重，產生中文日報。

關注方向包括：OPC / 一人公司 / AI 賺錢案例、AI + 電商、AI 工具與 Agent 工作流、新技術與新模型、投融資動態。

這個 Web 站點是日報的線上閱讀介面，方便快速瀏覽、搜尋歷史內容，而不必每次開啟 Markdown 檔案。
